1 Image Compression
Image compression reduces the storage and transmission requirements of digital images by
removing redundancy while preserving acceptable image quality. Compression methods are
categorized into lossless (no information lost) and lossy (some information discarded, but
perceptually acceptable).
1.1 Fundamentals of Compression
1.1.1 Redundancy Types
• Coding redundancy: inefficient symbol codes (e.g., fixed-length coding).
• Interpixel redundancy: correlation among neighboring pixels.
• Psychovisual redundancy: information less perceivable to the human eye.

1.2 Lossless Compression Techniques
1.2.1 Run-Length Encoding (RLE)
• Stores sequences of repeated pixels as (value,count).
• Efficient for images with large uniform regions (e.g., binary images).
1.2.2 Huffman Coding
• Variable-length codes based on symbol probabilities.
• Code length inversely proportional to symbol frequency.
1.2.3 Lempel–Ziv–Welch (LZW)
• Dictionary-based compression algorithm.
• Builds a table of recurring sequences and replaces them with shorter codes.
• Used in GIF and TIFF formats.
1.3 Lossy Compression Techniques
1.3.1 Transform Coding
• Uses transforms (e.g., Discrete Cosine Transform, DCT) to decorrelate data.
• Most energy concentrated in a few coefficients.
• Quantization discards less perceptually important coefficients.
1.3.2 Vector Quantization (VQ)
• Groups image blocks into vectors.
• Each block mapped to nearest codeword in a predefined codebook.
1.3.3 Predictive Coding
• Predicts pixel value from neighbors; encodes the prediction error.
• Differential Pulse Code Modulation (DPCM) is a common example.

• Uses lossless DEFLATE algorithm (LZ77 + Huffman coding).

• TIFF: often lossless (LZW), supports multiple encodings.
• JPEG 2000: wavelet-based, supports both lossy and lossless modes.
• HEIF/HEIC: modern format using HEVC compression, efficient for mobile devices.
1.5 Applications
• Efficient storage and transmission (web images, medical imaging archives).
• Streaming and multimedia applications.
• Telemedicine and remote sensing, where bandwidth is constrained.
2 Morphological Image Processing
Morphological image processing is a set of non-linear operations related to the shape or
structure of features in an image. These techniques are widely used in binary and grayscale
images for analyzing geometric structures.
2.1 Basic Definitions
• Let A denote a binary image set representing foreground pixels.
• Let B denote a structuring element (SE), a small shape or kernel used to probe A.
• The structuring element has an origin, which determines its placement during opera-
tions.

2.7 Applications in Shape Analysis
• Boundary extraction: β(A) = A−(A⊖B)
• Hole filling: Iteratively dilating until the background is removed.
• Connected component analysis: Identifying distinct objects using morphological
filtering.
• Skeletonization: Thinning objects to one-pixel-wide representations.
• Shape descriptors: Aspect ratio, compactness, and convex hull derived from mor-
phologically processed images.
2.8 Applications in Vision
• Biomedical imaging: segmentation of cells, nuclei, and vessels.
• Industrial inspection: defect detection in manufactured components.
• Document analysis: text extraction, character recognition preprocessing.
• Object detection: refining candidate regions in foreground masks.
3 Case Studies in Computer Vision Applications
To illustrate how image processing and computer vision concepts are applied in real-world
systems, we discuss three case studies: face recognition systems, automated visual inspec-
tion, and medical image analysis. Each integrates the methods studied in earlier units
(preprocessing, feature extraction, machine learning, and deep learning).
3.1 Face Recognition Systems
Face recognition is one of the most widely deployed biometric technologies.
3.1.1 Pipeline
1. Face detection: Using Haar cascades, HOG+SVM, or CNN-based detectors (e.g.,
MTCNN).
2. Feature extraction:
• Classical: Eigenfaces (PCA), Fisherfaces (LDA), Local Binary Patterns (LBP).
• Modern: Deep embeddings from CNNs (FaceNet, ArcFace).
3. Classification/matching: Compare feature vectors using cosine similarity or Eu-
clidean distance.

3.1.3 Applications
• Security and surveillance.
• Smartphone authentication.
• Human–computer interaction.
3.2 Automated Visual Inspection (AVI)
AVI systems are used in manufacturing and quality control.
3.2.1 Pipeline
1. Image acquisition under controlled lighting.
2. Preprocessing: filtering, normalization.
3. Defect detection using:
• Morphological analysis for scratches, cracks.
• Texture analysis for surface quality.
• CNNs for automated defect classification.
4. Decision: pass/fail based on tolerance thresholds.
3.2.2 Applications
• Semiconductor wafer inspection.
• Textile and fabric defect detection.
• Automotive component inspection.
3.2.3 Advantages
• High accuracy and consistency compared to human inspection.
• Reduced cost due to automation.
• Real-time processing capability.
3.3 Medical Image Analysis
Computer vision has become critical in modern medical diagnosis and research.
3.3.1 Pipeline
1. Image acquisition: X-ray, MRI, CT, ultrasound.
2. Preprocessing: noise reduction (Gaussian, median), normalization.
3. Segmentation: thresholding, region growing, U-Net models.
4. Feature extraction: shape, texture, intensity descriptors.
5. Classification: ML/DL classifiers for disease diagnosis.
3.3.2 Applications
• Tumor detection and segmentation in MRI/CT.
• Automated classification of chest X-rays (COVID-19, pneumonia).
• Retinal image analysis for diabetic retinopathy.
• Orthopedic analysis (e.g., knee osteoarthritis grading).
3.3.3 Challenges
• Variability in patient data (age, anatomy).
• Noise and artifacts in imaging modalities.
• Requirement for explainable AI in clinical use.
