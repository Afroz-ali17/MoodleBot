This concept introduces the foundational concepts in Computer Vision (CV) and Digital
Image Processing (DIP)withhistoricalbackground, definitions, andarangeofreal-world

2 Definitions and Scope
2.1 Digital Image Processing (DIP)
A digital image is a two-dimensional function:
f(x,y) (1)
where x and y denote spatial coordinates and f(x,y) represents the intensity (gray level) at
that point.
For a digital image:
• x,y ∈ Z+ (discrete spatial positions)
• f(x,y) ∈ {0,1,...,L−1} where L is the number of gray levels
Digital Image Processing involves:
• Image enhancement (contrast stretching, histogram equalization)
• Noise removal (median, Gaussian filters)
• Compression (JPEG, PNG)
• Restoration and reconstruction

2.2 Computer Vision (CV)
Computer Vision is the field concerned with enabling computers to interpret, process, and
understand images and videos.
Goal: Extract meaningful information (shapes, objects, actions, semantics) from raw
visual data and infer properties about the real world.
Three Levels of Processing
1. Low-Level: Image-to-image transformations (e.g., noise reduction, contrast adjust-
ment)
2. Mid-Level: Image-to-features (e.g., edge detection, segmentation, object proposal)
3. High-Level: Image-to-meaning (e.g., object recognition, scene understanding, activ-
ity detection)
2.3 Scope in AI & ML
Computer Vision and Image Processing are integral to AI-based systems:
• Preprocessing for CNNs and vision transformers
• Feature extraction and dimensionality reduction
• Data augmentation in training pipelines
• Object detection and semantic segmentation
3 Historical Development
3.1 Digital Image Processing History
• 1960s: Space exploration led to the first practical use of DIP (e.g., NASA’s Ranger 7
mission, 1964).
• 1970s: Image enhancement and filtering techniques were developed.
• 1980s: Personal computers made image processing more accessible.
• 1990s–2000s: Integration with signal processing and multimedia applications.
3.2 Computer Vision Evolution
• 1970s: Vision was part of symbolic AI. Early models based on geometry and algebra.
• 1990s: Shift toward statistical learning methods (e.g., SVM, PCA, k-NN).
• 2000s–2010s: Emergence of data-driven CV. ImageNet, HOG, and SIFT.
• 2012 Onwards: Deep learning revolution. CNNs (e.g., AlexNet), R-CNN, YOLO,
ResNet, Vision Transformers.
3.3 Key Milestones
• 1964: Ranger 7 sends first digital moon images.
• 1982: Marr’s theory of early visual processing.
• 1999: Viola–Jones face detection algorithm.
• 2012: Deep convolutional networks outperform traditional methods.
3.4 Applications
3.4.1 Industrial Applications
• Quality inspection in manufacturing
• OCR in banking and postal services
• Medical image analysis (CT, MRI, X-ray)
• Biometric authentication (fingerprint, iris, face)
3.4.2 Consumer Applications
• Face detection in smartphones
• Augmented reality (e.g., Snapchat filters, ARKit)
• Automotive vision for ADAS (Advanced Driver-Assistance Systems)
• Video stabilization and panorama stitching
3.4.3 AI and Robotics Integration
• Vision-based navigation in autonomous vehicles
• SLAM (Simultaneous Localization and Mapping)
• Drone object tracking and mapping
• Human-robot interaction

4 Image Formation and Representation
The process of capturing and representing visual data digitally is foundational to both image
processing and computer vision. This concept introduces the principles of image formation,
digital sampling, quantization, and color representation, preparing students for deeper un-
derstanding of filters, feature extraction, and AI pipelines.
5 Image Acquisition Methods
5.1 Imaging Sensors
An image sensor converts light (photons) into electrical signals. The most common types
are:
• CCD (Charge Coupled Device)
• CMOS (Complementary Metal Oxide Semiconductor)
These sensors consist of a 2D array of light-sensitive elements called photosites, which
correspond to pixels in the final image.

• Thermal/infrared cameras
• LiDAR for 3D range imaging

7 Color Spaces and Models
Color images contain 3 components. The most common representation is RGB.
7.1 RGB (Red-Green-Blue)
Each pixel is represented as:
Pixel(x,y) = [R(x,y),G(x,y),B(x,y)]
Common in displays and cameras.
7.2 Grayscale Conversion
Convert RGB to grayscale using a weighted sum:
I(x,y) = 0.299R+0.587G+0.114B
7.3 HSV (Hue-Saturation-Value)
More intuitive for humans:
• Hue: Color type (angle on color wheel)
• Saturation: Intensity or purity of color
• Value: Brightness
Useful for color-based segmentation.
7.4 YUV and YCbCr
Used in video compression (e.g., MPEG, JPEG):
• Y: Luma (brightness)
• U,V: Chrominance (color information)
Advantage: Allows subsampling of chroma channels for compression.
7.5 CIE Color Models
CIE XYZ and CIE Lab are perceptually uniform color models used in color calibration.
7.6 Applications in AI & ML
• CNNs expect normalized RGB or grayscale images
• HSV is used in skin detection and object tracking
• Quantization and sampling affect model robustness
• Data augmentation pipelines simulate variations in sampling and color
Understanding image formation, sampling, and color spaces is critical for developing
vision systems. These operations define the nature and quality of the data that modern
deep learning models rely on. Errors in acquisition or quantization can lead to significant
downstream model failures or hallucinations.
8 Fundamentals of Image Processing
Image enhancement techniques improve the appearance or interpretability of an image. In
this concept, we focus on point operations, which modify the intensity of each pixel inde-
pendently, and histogram processing, which helps in global contrast enhancement.
9 Point Operations
Point operations work on individual pixel values without considering their neighbors.
9.1 Brightness Adjustment
Let f(x,y) be the input image and g(x,y) be the output image. Brightness adjustment is
given by:
g(x,y) = f(x,y)+β (4)
• β > 0: increases brightness
• β < 0: decreases brightness
Pixel values must be clipped to remain in the valid range (e.g., 0 to 255 for 8-bit images).
9.2 Contrast Adjustment
Contrast is adjusted by scaling the dynamic range:
g(x,y) = α·f(x,y) (5)
• α > 1: higher contrast
• 0 < α < 1: lower contrast
Combining both:
g(x,y) = α·f(x,y)+β (6)
Example:
α = 1.2, β = 30 ⇒ brighter and more contrasted image
9.3 Negative Transformation
To obtain the image negative:
g(x,y) = L−1−f(x,y) (7)
Where L is the number of gray levels (e.g., L = 256 for 8-bit).
9.4 Logarithmic and Power-Law (Gamma) Transformations
These are nonlinear mappings used to enhance dark or bright regions.
Log Transformation:
g(x,y) = c·log(1+f(x,y)) (8)
Power-Law (Gamma) Transformation:
g(x,y) = c·f(x,y)γ (9)
• γ < 1: enhances darker regions
• γ > 1: suppresses brighter regions
These are used in gamma correction in displays and data normalization in CNNs.

14.4 Applications in AI & ML
• Edge-preserving filters improve feature maps in CNNs.
• Frequency filters are used in adversarial defense.
• Fourier-based layers appear in FNet and frequency transformers.
• Restoration filters are used in satellite and medical imaging.
Spatial and frequency domain filtering are two fundamental paradigms in image pro-
cessing. While spatial filters are intuitive and localized, frequency methods enable global
filtering and restoration. Understanding both is essential for building robust computer vision
systems and preprocessing data for AI/ML tasks.
