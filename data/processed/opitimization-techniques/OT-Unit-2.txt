Introduction to Transportation problem:
Transportation problem is a special class of liner programming problem. It deals with the
transportation of a commodity from n sources to n destinations. the data of the
transportation model includes:
1) Level of supply at each source and the amount of demand at each destination.
2) The unit transportation cost of commodity from each source to each destination.
Transportation or distribution methods of solving linear programming problems
aim at minimizing costs of sending goods from dispatch stations to receiving ends.
Generally, specific quantities of goods are shipped from several dispatch stations to
number of receiving centers. Linear programming approach in such situations tends to find
how many goods may be transported from which dispatch station to which receiving end
in order to make the shipment most economical. Transportation technique in such
problems gives a feasible solution which is improved in a number of subsequent steps till
the optimum (best) feasible solution is arrived at.

Origin: It is the location from which shipments are dispatched.

Transportation Method
Transportation model is the problem of determining the minimum cost for allocating a
product from several supply sources to several destinations.
A simplified version of the simplex method talked about in case of Linear Programming can
be used in solving such problems and this simplified version is often known as the
Transportation algorithm. At times this is also known as the Transportation method.
For example, a cold drink manufacturing company has, say four plants located in four
different cities and the total production of these four plants is absorbed by four shops located
in four different cities and if we are to determine a Transportation schedule that minimizes
the total cost of transporting cold drinks from different plant locations to various shops, then
it is a case of Transportation problem.
Nature of Transportation model:
1. Human factor affects the system behavior.
2. Objectives are many, and not well-defined.
3. Many elements, Transportation and non- Transportation, are involved in complex
manner.
4. The system performance changes dynamically over time with the changes in the socio-
economic system.
5. The solution, if found, are local, not universal.

Assignment Model
An assignment problem is one that involves the assignment of n different facilities to n
different tasks. For instance, we have three men available and three jobs to be done. Each man
is capable of doing any job but due to either individual quality, it takes them different anoi8nts
of time to do each job. The problem is how to assign the men to jobs in such a way so as to
minimize the total time spent on the jobs. This is an example of assignment problem. This
problem can be structured in the transportation frame-work with the men being the supply
sources, the jobs the destinations, and costs the time is takes man i to perform j jobs.
Defining Assignment model:
Given n resources (or facilities) and activities (or jobs) and effectiveness (in terms of cost,
profit, time..etc.) of each resource (facility) for each activity (job), the problem lies in assigning
each resource to one and only one activity (job) so that the given measure of effectiveness is
optimized.

Hungarian Method:
Step 1: Subtract from each row the lowest cost in the row.
Step 2 : From this new cost matrix subtract from each column the lowest cost in the
column.
Step 3: Draw the minimum number of horizontal and vertical lines necessary to cover all
zeros at least one. If the minimum number of lines is ‘n’ in a nxn matrix, then we have an
optimal solution for the given assignment problem corresponding to a set of independent
zero’s.
i.e., a set of zero’s such that no two zero’s in the set occurs in the same row of column.
Step 4 : if the minimum number of line in a nxn matrix is less than ‘n’, then select the
smallest number that doesn’t have line through it.
Step 5: subtract this number from all elements that have no lines through them and add it
to all elements that have two lines (intersecting) through them. Try for a solution among
the news set of zero’s applying the step 3 again. if one cannot be found, repeat this step
and continue using step 3 and step 4 above until a solution is found.
Step 6: Given the optimal solution make the job assignments as indicated by the zero’s
elements. This is done as follows:
i) Locate a row which contains only one ‘zero’ element. Assign the job corresponding to
this element to its corresponding person. Cross out zero’s if any, in the column
corresponding to the element which is indicative of fact that the particular job and person
are no more available.
