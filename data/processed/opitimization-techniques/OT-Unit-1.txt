Introduction:
Optimization techniques refer to mathematical methods and computational
procedures used to find the best possible solution or outcome from a set of available
alternatives. These techniques are applied to problems in various fields, such as
engineering, economics, logistics, finance, operations research, and artificial intelligence,
among others. The goal is to maximize or minimize some objective function while
satisfying certain constraints.
Meaning of Optimization Techniques:
Optimization is the process of finding the most efficient solution to a problem under
given conditions. It involves:
Objective Function: This is the function that needs to be maximized or minimized (e.g.,
profit, cost, efficiency, etc.).
Decision Variables: These are the variables or parameters that can be controlled or
adjusted to achieve the objective.
Constraints: These are the restrictions or limitations imposed on the decision variables,
which may include resource limitations, time constraints, or other factors that must be
considered while optimizing.
Optimization techniques aim to find the set of decision variables that provide the best
value of the objective function while respecting the constraints.

Nature of Optimization Techniques :
The nature of optimization techniques can be described as follows:
Mathematical Foundation: Optimization methods are grounded in mathematical theory,
particularly in fields like calculus, linear algebra, and mathematical programming.
Problem-Specific: Different optimization problems require different techniques. For
example, linear programming might be used for linear problems, while non-linear
programming or genetic algorithms could be used for more complex, non-linear problems.
Iterative Process: Many optimization techniques, especially those applied to large-scale
or complex problems, require iterative methods, where solutions are progressively
improved through steps until an optimal or satisfactory solution is found.
Global vs. Local Optimization: Optimization can be classified into global optimization
(seeking the absolute best solution across all possibilities) and local optimization (seeking
the best solution within a particular region or subset of the search space).

Linear programming
The most important function of management is decision making. A large number
of decision problems faced by an executive involve optimum allocation of scarce resources
to various activities with the objective of increasing profits or decreasing costs or both. The
decision problem becomes complicated when a number of resources are required to be
allocated and there are several activities to perform. The problem can be well handled by the
technique of linear programming.
Linear programming is a mathematical technique. This technique is applied for choosing the
best alternative from a set of feasible alternatives.
In LPP objective functions as well as restrictions or constraints can be expressed as linear
mathematical functions. This LPP technique is designed to help managers in planning,
decision making and to allocate the resources.
Components of LPP:
Objective Function: Objective function is that linear function which is either to be
maximized or to be minimized. The objective function is also known as the “criterion
function”.

Steps for graphical solution of linear programming problem
Step 1 : the constraints of the problem are taken as equalities and plotted on the graph
paper. The region satisfying each constraint is determined and then the region common to
all the constraint relations is located. This region is known as feasible region for the
problem as all points lying in this region will simultaneously satisfy the given constraints.
The solution set of the system of constraints is found to be represented by some convex
polygon termed as feasible region.
Step2 : Objective function is also plotted on the same graph paper by taking some arbitrary
value of z.
Step 3 : Trail and error method is used to locate the optional solution inside the feasible
region determined in step (1) so that the objective function is optimized. It is experienced
that the optional solution is located near the extreme points of the feasible region. Thus the
optimum feasible point should be searched only at the corners of the convex polygon.
The graph for all the constraints and the objective function will be straight lines in linear
programming problem.

linear equation where there are more/less unknowns than the number of equations.

Big-M method or Penalty method:
The big-M method is another method of removing artificial variables from the basis.
In the method, we assign coefficients to artificial variables, undesirable from the
objective function point of view. If objective function Z is to be minimized, then a
very large positive price (called penalty) is assigned to each artificial variable.
Similarly, if Z is to be maximized, the a very large negative price ( also called
penalty) is assigned to each of these variables. The penalty will be designated by –M
for maximization problem and +M for minimization problem, where M > 0.

Two phase method:
As an alternative to the Big –M method, there is also available another method for dealing
with LPP involving artificial variables. This is called the Two-phase method and as its name
implies, it separates the solution procedure into two phases. In the first of this method, the sum
of the artificial variables is minimized subject to the given constraints (known as auxiliary
LPP ) to get a basic feasible solution to the original LPP. Second phase then optimizes the
original objective function starting with the basic feasible solution obtained at the end of phase
1.

basic feasible solution.

Variants of Simplex Method:
Here we present certain complications and variations encountered in the
application of the simplex method. These are called the variants of the simplex method.
The following Variants are being considered.
1. Unbounded solution
2. Multiple solutions
3. Infeasible solution.
4. Degeneracy.

Unbounded solution:
It occurs when there is no constraint on the solution so that one or more of the
decision variables can be increased indefinitely without violating any of the restrictions.
It occurs in maximization problems, e.g., when a solution variable can be made infinitely
large without violating a constraint. It is discovered in simplex method if at any iteration
stage , all the entries in minimum ratio column are infinite (or) negative.

Infeasible Solutions:
It has already been stated that a solution is called feasible if it satisfies all the
constraints and the non-negativity conditions. Sometimes it is possible that the constraints may
be inconsistent so that there is no feasible solution the problem. Such a situation is called
unfeasibility and such instance is referred to as a non-feasible solution. A solution is also non-
feasible if an artificial variable appears in the basis of the solution purported to be optimal.
Degeneracy :
while solving a LPP under the simplex method, a situation may arise in which there
is a tie between two or more basic variables for ‘leaving the basis’, i.e., the minimum ratio to
identify the basic variable to the basis is not unique or the values of one or more basic
variables in the solution column become equal to zero. This causes the problem of degeneracy.
Degeneracy may occur during iterations in simplex method. In most of the cases,
when there is a tie in the minimum ratios, the selection is made arbitrary. However, adopting
the following rules can minimise the number of iterations required to arrive the optimum
solution.
1) Divide the coefficients of the slack variables in the simplex table where degeneracy is
detected by the corresponding positive numbers of the key column in the row starting from
left to right.
2) The row that contains the smallest ratio, comparing from left to right, become the key row.
